## 완료

* **열기**: 고정 후보 v3-mix(해시 `39e9a93eebd5…`)로 blind4를 한 번 열었다. 시스템 5개(원음, v3-mix, v2 base, v3-real, v1 base), Whisper small.en GPU, 652장면 × 5 = 3,260행이다.
* **사고**: 평가와 `eval/comparison.json` 저장은 끝났지만, `result.json`을 쓰다가 멈췄다. 규칙 파일의 개정 날짜(YAML date)를 JSON으로 바꾸지 못했다.
  * 판정은 저장된 행과 승인 규칙만으로 정해진다. `blind4_finalize` 단계가 접근 기록과 행의 해시가 같은지 확인한 뒤 `result.json`만 다시 썼다. 오디오를 읽거나 모델을 돌리지 않았으므로 다시 연 것이 아니다.
  * 고장 재현 시험 `test_blind4_result_serialises_rule_amendment_dates`를 추가했다.
* **판정**(세션 평균, `gate.decide`, 승인 규칙 그대로)

  | 요구 | 결과 | 판정 |
  | --- | --- | --- |
  | REQ-303 (기준 대비 SI-SDRi ≥ +1.5 dB) | +0.93 dB (CI +0.49~+1.40) | **미달** |
  | REQ-305 (기준 대비 cpWER ≤ −3.0 %p, CI 상한 < 0) | −5.15 %p (CI −12.07~+1.92) | **보류(유의하지 않음)** |
  | REQ-402 cpWER (원음 대비 ≤ −15 %) | 0.823 → 0.908, +10.4 % | 미달 |
  | REQ-402 DER (원음 대비 ≤ −5 %p) | 0.920 → 0.593, −32.7 %p | 통과 |
  | REQ-402 종합 | | **미달** |
  | REQ-405 회귀 (WER 악화 < 0.5 %p) | −3.55 %p | 통과 |

* **참고(사후 선택 불가)**: v3-real은 v3-mix보다 SI-SDRi +1.37 dB, cpWER −17.5 %p 낫다. 원음 대비 cpWER −9.0 %p(상대 약 −11 %)로, 이것도 REQ-402 기준에는 못 미친다.
* **해석**
  * blind3(AMI TNO)의 +3.36 dB가 새 장소에서는 +0.93 dB로 줄었다. 원음 대비로는 0과 구분되지 않는다.
  * 방·화자·장비 차이와 배열 형상 가정(ch0 가운데, 4.25 cm 원) 중 무엇이 원인인지는 이번 시험으로 나눌 수 없다.
  * DER은 모든 분리기에서 크게 줄었다. cpWER은 후보가 원음보다 나쁘다. 스트림 누설이 ASR을 해친다.
* **하지 않은 것**: 후보를 v3-real로 바꾸지 않았다. 규칙·기준·세션 수를 바꾸지 않았다. blind4를 다시 평가하지 않았다.
