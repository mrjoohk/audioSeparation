## 이번에 완료한 항목

* 실제 ASR(Whisper small.en)로 WER 측정.
* 실측 dev(AMI 4세션 160장면) 비교. 이어서 사전 규칙대로 후보를 고정하고 blind_test(80장면)를 한 번 열었다.
* 실측 보정·적응 효과 검증. 신경 분리기 입력 특징에 대역별 CORAL을 연결해 라벨 없는 dev-a로 맞추고 dev-b에서 측정했다. SI-SDRi가 base −1.34 / robust −0.71 / cal −0.79 dB로 나빠져 세 모델 모두 채택하지 않았다(사전 규칙: CI 하한 > 0).

## 결과 요약

| 평가 | 원음 | base | robust | cal |
| --- | --- | --- | --- | --- |
| AMI dev SI-SDRi (dB) | 0 | 1.18 | 1.61 | 1.81 |
| AMI dev DER / WER | 0.74 / 0.46 | 0.50 / 0.95 | 0.45 / 0.85 | 0.43 / 0.82 |
| AMI blind_test SI-SDRi (dB) | 0 | 0.16 | — | −1.84 (고정 후보) |
| LibriSpeech 시험 SI-SDRi (dB) / WER | 0 / 0.60 | 1.13 / 0.76 | 1.39 / 0.94 | 0.86 / 0.98 |

* 분리는 DER을 일관되게 낮췄다. WER은 악화했는데, 분리 스트림에 다른 화자가 남아 단어가 두 번 인식되기 때문이다(표본 확인).
* REQ-303(미지 영역 +1.5 dB)은 실측 미지 영역에서도 미달이다. blind_test에서 cal은 base보다 −2.00 dB(CI −2.48~−1.53)였다. 추적표 상태는 `not_met`이다.
* REQ-305(후속 태스크로 격차 축소 입증)는 차단에서 `not_met`으로 바뀌었다. WER 근거가 생겼으나 개선이 없었다.
* REQ-W05는 측정 HRTF(HUTUBS) 연동으로 차단이 해소됐다.
* 추적표: 검증 29, 차단 1, 미달 2, 누락 0. 전체 시험 596개 통과.
