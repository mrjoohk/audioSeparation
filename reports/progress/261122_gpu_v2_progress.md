## 이번에 완료한 항목

* **GUI 실제 브라우저 확인(단계 2, 차단 해소)**: Smart App Control이 꺼진 뒤 Gradio 6.32가 로드된다. `app.py`를 띄워 6개 탭을 확인했다.
  * 브라우저 조작으로 확인: 장면 생성(요약·오디오 표시), 배치 2/2, Zoom 미리보기, 설정 내보내기.
  * 업로드가 필요한 기능은 같은 서버의 API로 확인: 결과 보기, 설정 가져오기(서명 유지), 파일 실행 2/2.
  * Zoom 참가자 슬라이더에 "저장은 n±2에서 뽑는다" 안내를 추가했다.
* **GPU 학습**: torch 2.15+cu132(RTX 2060 SUPER). 증강이 CPU 병목이어서 스레드 배치 생성기를 추가했다(`loader_threads`, 시드 재현).
  * 프로세스 종료 시 0xC0000409로 끝나는 문제를 단독 재현으로 cuDNN 드롭아웃 상태까지 좁혔다. 체크포인트 저장 뒤의 일이다. 학습 스크립트는 종료 처리를 건너뛴다.
* **v2 재학습**: LibriSpeech train-clean-100 + dev-clean(291명, v1은 40명), 모델당 1,800장면, 30,000 스텝, 배치 16. 모델당 1.3–1.8시간.

* 증강 모델(robust, cal)은 합성·미지 배열에서 좋아졌다. AMI dev 절대값은 세 모델 모두 v1보다 낮다.
* AMI dev에서 cal은 base보다 +1.46 dB(CI 0.90~2.06)였다(v1 +0.63). 하지만 dev는 판정 자료가 아니다. v1에서는 dev 이득이 blind_test에서 −2.00 dB로 뒤집혔다.
* REQ-303: `not_met` 유지. blind_test 회의(TS3003a/b)는 v1 후보가 이미 한 번 사용했으므로 다시 열지 않았다.
* REQ-304: 사전 규칙상 robust+CORAL이 채택 조건을 충족했다(v1은 세 모델 모두 손해). 3개 모델 다중 비교를 보정하면 CI가 −0.05~1.49 dB로 0을 포함한다. 새 회의로 재확인이 필요하다.
* REQ-305: `not_met` 유지. 분리 후 WER이 원음보다 나쁘다.
* 추적표: 검증 29, 차단 1, 미달 2, 누락 0.
* 전체 시험 597개 통과(CPU가 빈 상태). Whisper 평가와 동시에 돌렸을 때는 `test_req201_sampling_speed_constraints_duplicates`가 10 s 제한을 넘었다(10.6 s). 이 시험은 부하에 민감하다.
