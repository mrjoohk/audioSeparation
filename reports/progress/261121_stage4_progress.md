## 이번 단계에서 끝난 것

* `src/datagen`: 자산 라이브러리(실제 WAV 등록 API + 합성 대리 자산), 시나리오 계획기, QC 게이트, 불변 버전 릴리스.
* REQ-201: 시나리오 1만 건 7.9 s, 중복 0, 제약 위반 0.
* REQ-202: 음원 역할(speech/noise/interference)과 목표 SNR을 렌더러가 선형 성질로 정확히 맞춤. 시험 ±1 dB 통과.
* REQ-203: VAD 기반 중첩을 단계별 누적 비율로 계획. 렌더 결과 easy 0.000 / medium 0.196 / hard 0.489 (목표 0 / 0.2 / 0.5, 허용 ±5 %).
* REQ-204: 1 ms VAD 라벨이 깨끗한 음원 기준 VAD와 F1 > 0.999.
* REQ-205: 클리핑 주입 장면만 정확히 거부, 릴리스 클리핑 0건, 같은 버전 재발행 거부, 체크섬 변조 감지.
* REQ-206: 화자 100·잡음 50에서 80/10/10 분할 교집합 0.
* 렌더러 추가: `mix.max_peak_dbfs` 음향 헤드룸 제어(장치 이득 클리핑은 그대로 검출).
